## Описание проекта
Сервис для создания и совместного ведения списков покупок. Пользователи могут создавать списки, добавлять товары и делиться ими с друзьями или семьей.

## Функции первой версии (5–7 функций)
1. Регистрация и вход пользователей.
2. Создание нового списка покупок.
3. Добавление товаров в список.
4. Отметка товаров как «куплено».
5. Удаление товаров и списков.
6. Приглашение человека в список по ссылке.
7. Страница «Мои списки» (отображение своих списков и тех, куда пригласили).
