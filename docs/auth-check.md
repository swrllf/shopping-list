## Проверка смены пароля (для Команды 3)
1. Зашли под тестовым пользователем.
2. Перешли в раздел "Profile" (или "Настройки").
3. Ввели текущий пароль, новый пароль и подтверждение.
4. Нажали "Сохранить".
5. Вышли из системы и попробовали войти со старым паролем (не пустило).
6. Вошли с новым паролем (успешно).
